#Comunicación Cliente-Servidor con Sockets en Python
##Descripción
Este proyecto implementa un sistema básico de comunicación cliente-servidor utilizando sockets TCP en python

El objetivo es comprender cómo dos programas pueden comunicarse a través de la red mediante el modelo cliente-servidor, donde:
- El servidor escucha conexiones entrantes en un puerto específico.
- El cliente se conecta al servidor y envía un mensaje.
- El servidor recibe el mensaje y envía una respuesta.
Este ejercicio permite entender conceptos fundamentales de programación en redes

##Tecnologías utilziadas
- Python
- Sockets TCP
- Protocolo TCP/IP
